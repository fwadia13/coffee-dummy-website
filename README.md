#  The Copper Kettle – Vintage Café Website

A beautifully designed vintage-inspired café website for **The Copper Kettle**, featuring an elegant user interface, interactive menu system, shopping cart functionality, checkout flow, and order management.

##  Overview

The Copper Kettle is a responsive café website that combines classic aesthetics with modern e-commerce functionality. Customers can browse the menu, add items to their cart, provide delivery details, choose a payment method, and place orders seamlessly.

##  Features

###  User Interface

* Vintage café-inspired design
* Fully responsive layout
* Smooth animations and transitions
* Interactive navigation menu
* Mobile-friendly experience

###  Menu System

* Categorized menu items:

  * Coffee
  * Tea & More
  * Food
* Item descriptions and pricing
* Search and filtering functionality
* Interactive menu cards

###  Shopping Cart

* Add items to cart
* Update item quantities
* Remove items from cart
* Dynamic cart total calculation
* Empty cart option
* Persistent cart using Local Storage

###  Checkout Process

* Customer information collection
* Delivery address form
* Order summary review
* Form validation

###  Payment Methods

* UPI Payment Option
* Cash on Delivery (COD)
* Payment confirmation screen

###  Order Management

* Automatic order ID generation
* Order confirmation page
* Estimated delivery time display
* Order history tracking
* Local Storage-based persistence

###  Notifications

* Add-to-cart alerts
* Remove-item notifications
* Successful order confirmation
* Smooth toast messages
